# 数据流向（适用：引擎 ≥ 0.7.17）

> **这是一份版本化承诺**：同一个 minor 版本线内，默认去向不改变；要改只在 minor
> 升级时改，并在 CHANGELOG 单列。
>
> 背景：0.7.11（默认自部署、不外发）→ 0.7.14（部分任务改云端）→ 0.7.16（官方
> 代理全部交给云端模型服务商）在一周内变了三次。功能可以快速迭代，**默认数据去向
> 不能**——它比任何单项功能都更影响信任。

## 四种部署组合

| 组合 | 典型配置 | 生成 / 归因 | 视觉兜底截图 | api 步骤 | webhook 通知 | 用量查询 / 版本检查 |
|---|---|---|---|---|---|---|
| **A 官方代理** | `GEN_BASE_URL=https://mobileaitest.com`、`GEN_PROMPT_MODE=server` | 发往官方代理，再转交云端模型服务商（当前为阿里云百炼）；服务商按其自身条款留存 | 显式开启后同上 | 用例里写的地址 | 配置的地址 | 官方代理 / PyPI |
| **B 自带 Key** | `GEN_BASE_URL=<你的服务商>`、`GEN_PROMPT_MODE=local` | 直连你配置的服务商，**不经过 MAT 服务器** | 同左（可用 `GEN_VL_BASE_URL` 单独指定） | 同上 | 同上 | PyPI |
| **C 离线 + 本机** | `MAT_OFFLINE=1`，端点 `127.0.0.1` | 只到本机进程 | 只到本机进程 | 只允许本机 | 只允许本机 | 不发生 |
| **D 离线 + 内网** | `MAT_OFFLINE=1`、`MAT_PRIVATE_HOSTS=10.0.0.0/8,gpu-gw.corp.local` | 只到声明的私有端点 | 只到声明的私有端点 | 只允许私有端点 | 只允许私有端点 | 只允许私有端点 |

`MAT_PRIVATE_HOSTS` 支持 IP / 网段 / 精确主机名 / 点开头的后缀（`.corp.local`）。
网段只匹配 IP 字面量、不做 DNS 解析；`0.0.0.0/0`、`::/0`、只有一级的后缀、官方托管
主机（`mobileaitest.com`）会被拒绝。写法见 `offline.py` 模块说明。

## 各任务发送的内容

| 任务 | 发送内容 | 是否含截图 |
|---|---|---|
| `gen` / `convert` / `describe` / `diagnose` / `map` / `polish` | 文字描述、控件清单、页面图谱上下文 | 否 |
| `vision-locate`（视觉兜底） | 当前屏幕截图（可缩图，**坐标换算永远用原图**）+ 目标描述 | 是，仅在显式开启视觉兜底时 |
| `api` 步骤 | 用例里写的 URL 与请求体（凭据形态的键在证据里打码） | 否 |
| 运行结果通知 | 摘要文本 | 否 |
| `mat status` 用量查询 | 只发鉴权头，不发内容 | 否 |
| 版本检查 | 只发 `User-Agent` | 否 |

## 承诺的边界

- **MAT 只保证自己的进程**不连接上表之外的主机，**包括重定向的每一跳**；离线模式下
  不使用环境代理（`HTTP_PROXY` / `ALL_PROXY` 不生效）。
- **私有端点自己是否再往外转发，MAT 看不到**：例如 LiteLLM 网关转到云端模型、
  内网 matcloud 配了云端服务。这部分由部署方负责——不要把「离线：开」读成
  「内容绝对不出内网」。
- 逐主机访问明细**尚未**写入 `run.json`（后续版本补 `egress` 字段）。当前要确认
  配置是否符合预期，用 `mat doctor` 的「离线 / 私有端点」检查，或直接看 `.env`。
