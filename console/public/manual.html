MAT 控制台 · 使用手册

给移动 App 做自动化测试的本机控制台 —— 连设备、遍历探索、AI 生成用例、执行出报告，一条链路走完。

快速上手 功能分区 团队协作与成员 结果通知 常见问题

快速上手（5 步完成首次闭环）

  1. 连设备 —— 打开「设备/执行日志」，连接一台 Android 真机（USB 打开调试）或 iPhone；投屏画面正常显示即连接成功。
    iOS 支持模拟器与真机 beta，真机走 USB，首次需 mat ios-setup 体检（Xcode 里登录账号、设备信任证书并 ⌘U 一次）。真机限制：仅 USB（Wi-Fi 暂不支持）、须保持解锁且自动锁定设为「永不」、免费证书 7 天要续期、真机不支持录屏（模拟器可以）。页面图谱相关能力——页面索引、遍历探索、到达路径验证、断链修复——在 iOS 上会被明确拦下，Android 才是完整能力。
  2. 遍历探索 —— 打开「遍历探索」，选好被测 App 启动自动遍历：它会自己把 App 点一遍，发现崩溃、白屏这类异常，同时沉淀页面图谱（这是后续 AI 生成用例的依据）。遍历是规则驱动的，不消耗 AI 生成额度；默认带黑名单——支付、结算、客服、分享、退出登录，以及麦克风/相机/定位/通讯录/相册这类会弹系统权限弹窗的入口都不点；另有时长与步数双上限，到点即停。
  3. 生成用例 —— 打开「用例生成/导入」，用一句话描述测试场景（如「搜索一个关键词并验证结果页出现」），AI 依据页面图谱生成可执行用例；也支持导入 Excel / CSV / Markdown / 纯文本 / XMind 手工用例。
  4. 执行用例 —— 打开「用例管理/执行」，勾选用例、选设备后点「运行」；套件可批量执行并支持用例间冷启动。
  5. 看报告 —— 打开「报告」：每条执行都有截图、录屏、日志的完整证据链（录屏限 Android 与 iOS 模拟器，iOS 真机不录）；失败步骤可用「AI 归因」自动归类失败原因。
提示：不确定下一步做什么时，看「概览」页的下一步建议卡——它会根据当前环境自动给出唯一主行动和跳转按钮。

团队协作与成员

控制台跑在本机。首次进入（共享模式下）会要求填写团队成员名字：一个名字占一位——名额只随团队授权提供（标准/体验授权面向单人使用，--share 下也只有安装者本人 1 人）。任务与报告按「执行人」区分，操作记录可追溯。

  • 改名 = 换成员；同名重复进入不重复占用。误填/离职的名字可在「设置 → 使用方式」移除、释放名额（任何成员都能移除——这是内网协作的取舍，不是权限系统）。
  • 成员已满时新成员无法进入，扩容请联系客服（控制台「设置 → 使用方式」的成员说明里点「联系客服」跳转官网联系区扫码添加）。
使用方式口径：功能不分档、全员一致；本地执行 / 自愈 / 报告不设额度，跑前的质量闸门也是规则判断。官方代理的 AI 生成与视觉兜底按使用方式有月度上限（标准版 生成 2,000 / 视觉 300，体验版 生成 60 / 视觉 20，团队授权 生成 10,000 / 视觉 1,000；视觉兜底同一屏命中缓存不重复计）；自带 API Key 不设上限，余量用 mat status 看、调用次数与耗时用 mat ai-stats 看。多人共用控制台（--share）只随团队授权提供。

结果通知（可选）

执行完成后把结果推送到飞书/钉钉群。在 .env（控制台「AI模型配置」行的「配置」按钮可打开）加两行：

MAT_WEBHOOK_URL=https://open.feishu.cn/open-apis/bot/v2/hook/xxxx
MAT_NOTIFY_FORMAT=feishu（取值 feishu | dingtalk | generic，可省略）

  • 飞书：目标群 → 设置 → 群机器人 → 添加「自定义机器人」，签名校验保持关闭——通知是纯文本消息，不支持加签，开了会一直推送失败。
  • 钉钉：目标群 → 设置 → 智能群助手 → 添加「自定义（Webhook）」，安全设置选「自定义关键词」并填 MAT（通知内容以 [MAT] 开头，正好命中）；不要选「加签」。
说明：通知是尽力而为——推送失败不影响执行主流程；报告页始终有完整证据链。

常见问题

我的数据会被上传吗？

执行、截图与日志默认只存本机，不会自动上传。生成用例时发出的是文字描述与控件清单（不含截图）；只有开启视觉兜底后，定位失败时才会把当前屏幕截图发给你配置的模型服务。此外还有少量出站请求：激活时把机器标识的哈希上报一次（由你输入激活码触发）、加入/接受邀请时登记一次（由你点击触发）、控制台启动时查一次最新版本号（不带任何机器信息，MAT_NO_UPDATE_CHECK=1 可关闭）。

前面执行的日志怎么不见了？

任务记录存在内存里，服务重启即清空——这是正常设计；落盘的报告在「报告」页不受影响。

「可选步骤（onFailure=continue）」是什么意思？

启动广告、权限弹窗这类「可能出现也可能不出现」的前置步骤会标为可选：目标没出现时记 skipped 并继续执行，不算失败。引擎拉起 App 后也会自动清理广告与权限弹窗。

定位失败能自动救回吗？

有三级自愈：本地模糊重定位（不联网、不花额度）→ 页面图谱匹配 → 视觉兜底（VL 模型按控件截图位置定位）。被救回的步骤会出现在「自愈提案」，确认后回写用例。

用例列表里的 #N 编号是什么？

仅用于展示沟通的稳定序号（删除不回收）；对账以报告里的 caseId 为准。

报告怎么按人区分？

每条执行记录「执行人」（右上角填的名字）；套件批次行如有多人执行会显示「N 人」并在悬停时展开名单。
